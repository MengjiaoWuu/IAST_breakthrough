IAST_breakthrough

IAST_breakthrough is a MATLAB toolbox for simulating and analyzing adsorption breakthrough processes using Ideal Adsorbed Solution Theory (IAST).

This toolbox accompanies the publication:
Breakthrough Curve Prediction Using Ideal Adsorbed Solution Theory
ACS publication

Features
Predict adsorption breakthrough curves using IAST-based methods
MATLAB app for convenient installation and usage
Tutorial examples for quick start
Designed for adsorption process analysis and research applications
Installation

The toolbox can be automatically installed using:

IAST_Breakthrough.mlappinstall

Steps:

Download this repository
Locate IAST_Breakthrough.mlappinstall in the main branch
Double-click the installer file in MATLAB
Follow the installation instructions
